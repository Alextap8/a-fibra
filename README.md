# Proyecto A fibra

Documento de trabajo del proyecto, publicado en https://alextap8.github.io/a-fibra/

La página está cifrada con [StatiCrypt](https://github.com/robinmoisson/staticrypt): sin la contraseña no se puede leer, tampoco desde este repositorio.

`.staticrypt.json` guarda la sal del cifrado. No es secreta y conviene mantenerla igual entre versiones para que «Recordar en este dispositivo» siga funcionando al actualizar.
